# Scrcpy Harmony 1.0.3 发布记录

状态：**发布准备中**。这是依赖源码迁移前的恢复节点；功能基线为 `8087ac8`，发行准备仅修改版本与文档。发布完成前不开始依赖迁移。

## 发行内容与边界

包含 1.0.2 后已经合并的设备/应用读取隔离、概览有限读取、HDC 握手兼容、投屏会话与窗口生命周期、文本输入、HiLog 旧记录处理、WebView 发现与文本渲染、小工作区适配。详见 [CHANGELOG](../../CHANGELOG.md)。

保留现有 npm 依赖、`src/share` 与 `src/renderer/icon` 子模块，以及 HDC/uitestkit 资源下载流程。本版本尚不包含源码内置或离线构建改造。

目标平台：Windows x64、macOS arm64、macOS x64。无发行者签名或 macOS 公证承诺；各平台实际信任检查结果随发行产物归档。安装启动检查不等同于真机兼容性、无线调试、原问题时长的空闲稳定性、离线真实图标或受保护应用投屏已验收；这些状态继续见 [RUNBOOK](../../RUNBOOK.md)。

## 恢复方式

发布后可从 [v1.0.3 Release](https://github.com/MonsterXia/scrcpy-harmony/releases/tag/v1.0.3) 下载原始安装包。需要旧源码时，在独立目录 clone 本仓库，执行 `git checkout v1.0.3` 与 `git submodule update --init --recursive`，再按 [构建指南](../build-guide.md) 操作。不要在有未保存修改的目录强制重置。

tag 固定源码与子模块提交；外部设备资源仍来自上游可变地址，故重新编译不保证与已发布包逐字节相同。恢复已验收的可执行版本应优先使用 Release 中带校验值的安装包。
