# Scrcpy Harmony 1.0.2 发布记录

状态：**2026-10-22 已发布**。[下载 Release](https://github.com/MonsterXia/scrcpy-harmony/releases/tag/v1.0.2)。本版本接续上游 ECHO 1.0.1，为 Scrcpy Harmony 首次独立发行；M0-2 已完成，线上更新的 M0-3 仍待实际应用验收。

## 用户说明

- 更名为 Scrcpy Harmony，使用独立应用 ID `io.github.monsterxia.scrcpyharmony`，下载、反馈与更新源指向本仓库；保留上游署名、历史及 AGPL-3.0 许可证。
- 修复投屏图像与设备触控尺寸不同导致的点击偏移，明确投屏分辨率比例。
- **旧 ECHO 配置保留原处，不自动迁移**；新应用使用新的用户配置目录，首次启动需要重新配置设置。
- 支持 Windows x64、macOS Apple Silicon（arm64）与 Intel（x64）；Electron 45 要求 macOS 13 或更新版本。
- 更新检查提示用户打开本仓库 Releases 手动下载安装；本次尚未完成实际线上更新验收。
