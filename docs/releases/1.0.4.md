# Scrcpy Harmony 1.0.4 正式版

状态：**发布准备中，尚未公开**。用户已要求发布正式版；当前公开稳定版仍为 v1.0.3。本版基于 master `09fd66a1b59aa405aebaebefb8afee3443b1c75b`，包含已合入的 Beta Update 状态与菜单对齐修复；最终发行 SHA、CI/Build 和附件审计在通过验证后记录。执行计划见[1.0.4 发布计划](../superpowers/plans/2026-10-31-release-1.0.4.md)。

## 相对 1.0.3 的更新

- 原生 H.264 投屏，静止画面先显示 JPEG 首图；解码失败时回退 JPEG，支持自动及手动恢复视频。工具栏提供原画/流畅、格式/FPS、全屏和自动隐藏。
- 直接键盘、IME 和纯文本粘贴；手机内复制/剪切与粘贴，以及右键明确选择电脑或手机来源。手机剪贴板自动同步到电脑仍未提供。
- HAP 拖入主窗口或投屏窗口安装，支持大写扩展名和覆盖安装，完成后显示通知并刷新应用列表。
- 桌面异常退出、换电脑后空闲投屏残留的受限恢复，核验身份、已知库和活动连接；未知归属不执行批量清理。
- 商店查询有限等待、取消底层连接、合并请求及失败冷却；不可达时返回本地应用信息，恢复网络后可重试。
- 简体中文和英文选择，重启后生效；可取消的更新窗口及具体版本下载页。Beta Update／接收预发布更新明确显示开启/关闭，勾号可见，菜单文字统一对齐。
- HDC、Licia、Luna 与共享代码纳入本仓维护，安装包保留第三方许可声明。

## 安装和升级

计划提供 Windows x64、macOS arm64、macOS x64 三个平台；Mac 要求 macOS 13 或更新版本。安装包自带 HDC 和设备资源，普通用户无需 Node.js。

从 1.0.3 或开发版升级，请下载对应平台安装包并关闭旧应用后安装；应用 ID 和配置目录保持不变。检查更新位于应用菜单，仍由用户手动下载并安装。正式版不要求开启 Beta Update；开启后也应优先选择版本更高的正式版。旧版 v1.0.3 和各开发预发布保留。

## 签名和系统信任

用户已选择沿用 Windows 未签名、macOS 有效 ad-hoc 的方式。两个 Mac 架构必须通过 deep/strict 签名完整性检查，但没有 Developer ID 或公证，不能据此保证 Gatekeeper 放行；Windows 也不具备发行者签名。实际签名与安装报告随最终附件提供，不关闭全局系统安全策略。

## 已知边界

其他固件、Windows 内网、真实跨电脑换线、长期挂死、离线真实应用图标、受保护画面、完整无线调试仍按 RUNBOOK 跟踪。原生客户端不遵守应用的 advisory lock，最后活动连接检查与信号之间仍有短竞态；无法确认身份或未知库时不接管。不承诺所有机型/系统均可用。

严重故障时不能只把 Latest 指回 1.0.3：新更新器会选择仍公开的最高适用版本。需要按实际情况撤回问题版本的公开分发或发布 1.0.5，不覆盖既有 tag/二进制，不自动降级用户。
