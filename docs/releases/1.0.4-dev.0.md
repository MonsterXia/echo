## 本版内容

- 内置 hdckit、Licia、Luna 及共享源码，便于本仓维护；保留上游署名和许可。
- 原生 H.264 投屏、连接预热、流中断恢复、工具栏与画质/FPS 显示。
- 直接键盘/IME、文本选区、电脑到手机粘贴、手机内复制/剪切/粘贴及右键来源选择。

功能基线为已合入 PR #55、#56、#58 的 `cb288744d74d9038742f192b02bd082499ca22b8`；发布准备只追加说明，不修改应用代码。键盘功能已有全新上下文独立审查、578 项应用测试及 Windows 当前设备回归；安装包已通过本次同源 Build 验证，未复用先前构建的安装结论。

## 发行核验

运行手动 Build，固定同一源提交，在 Windows x64、macOS arm64/x64 打包、安装和启动后下载产物。核对三个 artifact 的来源、摘要及报告，逐项核对 YAML 版本、文件名、size 和 SHA-512，再以同源 tag 发布安装包、blockmap、元数据、验证报告与 SHA-256 清单。远端资产应与已验证字节一致；最终运行链接和校验结果保存在 Release 的发布说明与附件中。

macOS 最低要求为 13。签名、公证、Gatekeeper 结果以本次随包报告为准，安装启动成功不代表系统信任通过。手机到电脑复制需要设备接受的签名助手，当前未包含；实体手机直接复制与电脑重复复制相同文本无法自动辨识，可右键指定粘贴来源。人工中文候选窗、其他固件、多行长文本、物理拔插与长期运行仍需验收。
