# Scrcpy Harmony 1.0.4-dev.1 开发预发布

状态：**发布准备中（2026-10-26，Asia/Hong_Kong）**。基于 master `fe1dfd9`，本轮递增开发版本，不覆盖 dev.0；计划发布为 Pre-release，稳定版 Latest 保持 v1.0.3。下载地址：[v1.0.4-dev.1](https://github.com/MonsterXia/scrcpy-harmony/releases/tag/v1.0.4-dev.1)。

## 本版迭代

- [PR #65](https://github.com/MonsterXia/scrcpy-harmony/pull/65)：修复手动检查更新无反馈、Windows 菜单状态、结果被置顶投屏遮挡及下载页链接。
- [PR #66](https://github.com/MonsterXia/scrcpy-harmony/pull/66)：增加投屏控制超时后的受限恢复、连续失败上限及手动重试，保护 SDK 检查失败与其他控制客户端。
- [PR #67](https://github.com/MonsterXia/scrcpy-harmony/pull/67)：新增默认关闭的 Beta Update，开启后从正式与预发布版本中选择最高版本；即时更新窗口提供进度、取消和结果卡，跳转具体版本下载页。
- [PR #68](https://github.com/MonsterXia/scrcpy-harmony/pull/68)：补齐中英文翻译，提供系统/English/简体中文选择，重启后统一应用至菜单及窗口；开发流程加入词条完整性检查。

## 发布验证

发布前要求版本与锁文件一致、独立复审、同源五项 CI、Windows x64 / macOS arm64 / macOS x64 Build、实际安装启动，以及安装包、更新 YAML、blockmap、签名报告和下载字节校验。结果及运行链接在完成后追加；目前不得将这些检查视为已通过。

## 验收边界与下一步

本轮发布验证不替代真机测试。既有投屏恢复设备证据见[控制恢复记录](../maintenance/screencast-control-timeout.md)，语言与更新窗口的源码验收分别见[国际化记录](../maintenance/internationalization.md)和[Beta Update 记录](../maintenance/beta-update-ui.md)。跨固件、长期运行、物理断连矩阵及三平台人工双语视觉仍待验收；跨进程历史视频扩展残留的自动回收未实现。

从 dev.0 升级需下载本版安装包。安装本版后可在设置开启 Beta Update 检查后续预发布；更新功能打开下载页，由用户安装。语言切换需重启应用。macOS 最低版本为 13，签名、公证与 Gatekeeper 状态以本版实际报告为准。
