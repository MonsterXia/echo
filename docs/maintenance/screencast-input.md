# 投屏键盘与文本剪贴板

日期：2026-10-25。最初范围包括键盘输入、电脑到手机粘贴、手机到电脑复制及手机内部复制粘贴，不含 OCR。用户接受设备端助手，但确认没有真机签名环境后，将本轮收窄为「先完成键盘和向手机粘贴」。手机到电脑复制保留后续任务。

## 实现与使用

焦点文本使用 `uitest uiInput text`，不点击固定坐标；特殊键使用 `uinput -K` 按下/逆序释放。renderer 在 Canvas 同容器挂载 textarea 接收 IME，只在投屏获得焦点时转发，工具栏和弹窗保持本地输入。全屏目标包含 Canvas 和 textarea，按容器重新计算 Canvas 显示尺寸。

新增 `screencastInput(sessionId, action)` IPC，校验当前捕获窗口/主文档/会话代次。文本最多 64 KiB UTF-8、拒绝 NUL、以单引号安全编码；按键限制为 1～3 个允许范围的整数。有限 HDC shell 为 10 秒截止，核对设备退出标记与错误输出，不经过记录参数的通用 IPC 日志。关闭/导航/重新捕获时撤销会话并中止尚未发出的连接等待；已经到达设备的输入无法撤回，也不自动重试。

renderer 队列最多 64 项，失败、失焦、重新点击和销毁时丢弃未发送输入。主进程触摸与文本共用设备队列，防止未完成的文本跟随点击进入新字段；满队列仍接纳 touchUp，避免丢失手指释放。不记录正文。

| 操作 | 行为 |
| --- | --- |
| 点击手机输入框后打字 | 文本发送到当前手机焦点，IME 只发送提交文本 |
| 方向键、Shift+方向键、Home/End、Backspace/Delete、Enter/Tab | 手机光标、选区及编辑 |
| Ctrl/Cmd+A | 手机全选 |
| Ctrl/Cmd+V，原生菜单粘贴 | 自动选择来源：投屏内复制/剪切成功后使用手机剪贴板；电脑剪贴板文本变化后使用电脑文本 |
| Ctrl/Cmd+C、X | 手机内复制、剪切，不更新电脑剪贴板 |
| 右键菜单「粘贴电脑文本 / 粘贴手机内容」 | 手动指定来源，不必记额外快捷键；原 Ctrl/Cmd+Shift+V 保留为手机粘贴兼容入口 |

已有 UITest API 没有读取剪贴板正文的方法；PasteboardService 的 hidumper 仅含元数据。实验性原生程序/共享库被当前设备 XPM 签名检查拒绝（`Xpm check failed` / `Permission denied`），没有形成可用辅助程序，也未打包。设备端实验文件已清理。后续需要设备接受的已签名 HAP/原生组件，再验证权限和按需读写；不能用整棵 UI 文本代替用户选区。

## 验证记录

最新独立审查补充四处边界修复及 **578/578** 应用回归，见[独立审查记录](screencast-input-review.md)。以下 585/579 数量是历史阶段结果。

### 同日追加：统一常规复制粘贴

用户指出隐藏的 Ctrl+Shift+V 不易发现，改为常规 Ctrl+C/X → Ctrl+V。`ScreencastInput` 在复制动作发生时只读电脑剪贴板快照，设备复制成功后记录来源；自动粘贴在原输入队列中决策，等待前面的复制完成。电脑文本与快照不同则切回电脑来源，后续即使恢复旧文本也不会误用手机。快捷键直接调用粘贴逻辑，避免电脑剪贴板为空时 Chromium 不发 paste 事件；原生菜单 paste 事件同样支持自动选择。快照读取失败仍允许手机内复制粘贴，显式电脑粘贴读取失败会通知；延迟读取完成后再次核对焦点代次。

投屏右键菜单提供「复制、剪切、粘贴、粘贴电脑文本、粘贴手机内容」，复用同一输入队列和焦点保护，卸载移除监听、迟到菜单动作无效。常规 Ctrl+V 无需记 Shift。生产逻辑只读电脑剪贴板，不写路由标记、不后台轮询、不跨会话持久化正文。

当前仍不是双向系统剪贴板同步：直接在实体手机上点复制无法被自动观察；在电脑重新复制完全相同的文本也无法从文本比较辨识。这些情况可用右键菜单指定来源。手机剪贴板只表示当前系统内容，不承诺历史内容。首轮手动手机粘贴检查失败，探针在右键菜单关闭后未先恢复 textarea 焦点便按 Ctrl+A，且依赖更早的手机内容；没有据此宣称业务缺陷已复现，最终用明确建立的手机选区重新验收。

新增 6 项回归先失败后通过，覆盖普通复制/剪切到自动粘贴、电脑来源切换、显式来源、迟到读取取消、读取失败和电脑空剪贴板。最终应用 **585/585**，Licia 正常/回退各 **606 passing / 4 pending**，lint、renderer 构建通过。实际 Windows 应用通过 Ctrl+C/X→Ctrl+V、复制新电脑文本后自动切换、空电脑剪贴板、右键菜单项目与两个指定来源回调；原生菜单弹出由实际右键触发，菜单选择通过调用实际 MenuItem 回调验证，未冒称人工点选。验证后清空搜索框、重载投屏，完整格式备份重写成功且电脑剪贴板文本相等核对通过。脱敏统计见[融合粘贴验证](screencast-input-fusion-verification.json)。本轮没有改主进程、未重跑其构建；macOS/其他固件仍待验证。
