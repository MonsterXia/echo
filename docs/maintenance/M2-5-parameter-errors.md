## 行为

hdckit 0.12.1 的 getParameters 将非参数输出直接丢弃，导致 `[Fail]...` 被当作空参数对象，再由兼容回退生成可选设备。新增参数读取器使用公开 `Target.shell('param get')`，解析前拒绝行首 `[Fail]`、`[E` 加六位数字 `]`、`error:` 等明确错误。异常设备由现有逐设备隔离逻辑跳过，正常设备仍保留；概览也使用同一读取器。连接在读取结束或解析失败后关闭。

合法参数值中的错误标记不误判，可选元数据缺失仍兼容。本项只识别明确错误，不把所有未知输出定义为失败；不修改 HDC 服务生命周期或共享 shell 超时。工具栏在枚举失败后的通知由另一独立 PR 修复。
