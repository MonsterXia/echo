## 独立审查

使用不继承实现对话的新上下文审查代理，只读审查源码及测试；不操作设备、不修改源码。初版发现三项需要修复的问题：

- P1：候选扩展退出时，固定 socket 可能已属于其他工具，却被当成本次服务并发送 onStart/onEnd。每次候选部署前重新查占用，监听就绪、准备完成及正式激活核对本会话随机扩展进程；争用时不连接、不停止对方。
- P2：before-quit 无界等待后台控制初始化，HDC 不结束 shell 时退出/重启永久阻塞。现在立即取消准备并撤销活动帧路由，正常路径等待全部清理；最多 10 秒后记录“清理未确认”并 app.exit 终止进程，避免遗弃 Promise 后继续部署。强制退出不代表远端清理成功，设备资源或外部 HDC 子进程仍可能遗留。
- P2：后台预热可能因旧 SDK 或握手失败杀掉其他工具的控制 daemon。后台模式禁止替换已有 daemon 的 SDK，也不执行失败后的 stop 恢复；缓存 driver 的准备重连同样受此限制。需要破坏性修复时跳过预热，由用户显式前台操作沿用原恢复策略。

三个问题均有合成生产模块复现及修复前失败、修复后通过的回归。独立代理复审工作树未发现剩余实质阻断问题，独立运行四个修改测试文件 57/57 通过；最终提交仍须按 PR 门槛再核对。
