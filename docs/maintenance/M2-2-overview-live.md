# M2-2：完整概览 IPC 与失败恢复验收

2026-10-23，Windows x64、Node 22.21.1、Electron 45.0.0；一台已授权连接的手机。测试由主对话独占设备执行，侧载应用样本仍仅限 bilibili，本次概览验收未查询应用、安装 HAP 或执行设备写入。

## 验收范围

本次先在独立检出执行完整 `npm run build`，再运行 `script/check-overview-live.mjs` 启动临时用户配置的真实 Electron。调用链保留 renderer → preload → `ipcRenderer.invoke` → 真实 `getOverview` → HDC，以及实际概览组件的刷新、错误提示、清空和恢复。

随机回环端口代理连接已有 HDC 服务，只允许设备枚举、ready、五条固定概览命令和只读 `fport ls`。后者由概览中已挂载但未打开的端口映射对话框发起；脚本不建立或删除端口映射。启动配置使用不可执行的占位 HDC 路径，退出不停止已有服务。其他应用、日志、进程、投屏面板未访问。

故障在代理中注入，分别返回明确的合成失败帧或让本次读取没有回复。故障命令不发送给手机；生产 finiteShell 必须自行到期关闭连接。其余正常读取和后续恢复都使用真实手机。**这不是物理 USB 断连、系统授权失败或长期空闲复现。**

## 可重复步骤与证据保护

```powershell
npm run build
node script/check-overview-live.mjs <本地证据目录> --all-stages
```

需要一台已连接、已授权设备及已运行的 HDC 服务。省略 `--all-stages` 仅验证内存/屏幕，供旧基线对照。脚本总看门狗为 180 秒，终止只作用于本次代理和 Electron；正常/失败结束均删除临时用户配置。结果仅输出布尔值、命令计数、耗时、运行环境及源码/构建哈希，不输出设备标识、原始参数、应用清单、原始日志或截图。

候选 JSON 记录真实 main/preload 和全部 renderer 产物哈希，并核对实际页面来自该构建的 `dist/renderer/index.html`。独立审查发现初版 UI 内存条件可能接受“未知”、缺少 renderer 产物身份；已加强为全部九字段比较和有效内存断言，并记录实际资产。独立离线复审确认旧反例被拒绝，`node --check` 通过；随后才执行上述最终候选手机验收。基线 JSON 的脚本哈希对应早期版本，不能与最终版本混用。

## 保留待办

M2-2 继续保持“进行中”。本次补齐完整概览 IPC 和受控失败恢复；物理断连、长期空闲原复现时长、负载预算、跨设备/系统兼容和 CPU/内存/监听资源趋势仍未验收。`getTargets` 及其他旧 `base.shell` 消费者仍有独立的无限等待问题，不属于本次概览验收结论。脚本与证据的最终独立审查、CI 和合入状态以对应 PR 为准；没有发布新版本。
